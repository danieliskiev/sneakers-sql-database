# Sneakers Sales Database — SQL Server

A relational database project built with SQL Server to organize sneaker sales data into four connected tables: **Brands, Customers, Shoes, and Orders**.

## Project overview

The project transforms a flat CSV dataset into a structured database, reduces repeated brand, customer, and product information, and enforces data integrity using primary keys, foreign keys, and constraints.

**Tools & skills:** SQL Server, T-SQL, relational database design, JOINs, and data validation.

## Dataset

130 sales records · 18 brands · 20 customers · 106 distinct shoe records

All data is fictional and used for educational purposes. I made adjustments to the CSV dataset to fit the project requirements. Orders with identical details intentionally represent separate purchases, each assigned its own OrderID.
